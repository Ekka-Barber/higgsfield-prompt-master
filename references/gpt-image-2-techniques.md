# GPT Image 2 Prompting Techniques

Condensed from [awesome-gpt-image-2](https://github.com/YouMind-OpenLab/awesome-gpt-image-2) (16,635+ prompts, 9.7k stars — updated daily; check `~/.hermes/logs/gpt-image2-repo-state.json` for live counts) plus analysis of the full youmind.com gallery corpus via scraping (see `references/gpt-image2-prompt-database.md`).

**Important corpus finding:** The curated README (120 prompts, capped by GitHub content-length limits) skews toward flat photography prompts (83% flat, 3% JSON). The actual full corpus is **54% JSON-structured** and dominated by UI/UX designs. Weight JSON structure as the primary pattern, not the exception.

> **⚠️ Evidence policy (see `RESEARCH-2026-08.md`).** This file records **what the corpus contains** — observed community patterns, tracked since Aug 2026 by a daily watchdog (techniques 11–35 are each sourced to a specific prompt with author and date below). Corpus frequency is *not* evidence that a technique works as model guidance. Where vendor-primary-source research disagrees with corpus folklore, the engine (`data/*.json`, `profiles/*.yaml`) wins: **negative prompts do not exist** on GPT Image 2 or Nano Banana Pro (describe the positive state instead), **`REFERENCE_0` numbering is not a real input syntax** (address inputs by ordinal and role), and **JSON is an authoring format, not a superiority claim** (both target models are prompted in prose; vendors recommend flattening structured input). The techniques below are still documented because they are real observed craft — use them as pattern vocabulary, not as vendor-verified levers.

## Four Prompt Structures

### Structure A: JSON Object (PRIMARY — 54% of corpus)
GPT Image 2 parses JSON with high fidelity. Keys: `type`, `subject`, `style`, `background`, `header`, `layout` (with `centerpiece`, `left_section`, `right_section`, `footer`), `callout_labels`. Best for: UI mockups, exploded diagrams, infographics, posters, complex multi-zone layouts. This is the dominant structure in the full corpus.

### Structure B: Flat Paragraph (46% of corpus)
Single-subject, single-composition. `[SUBJECT] [STYLE] [TECHNICAL] [COMPOSITION] [BACKGROUND] [DETAILS] [CONSTRAINTS]`. Used for portraits, cinematic shots, simple illustrations.

### Structure C: Goal + Canvas + Sections (niche)
Complex multi-zone designs. Define `Goal:`, `Canvas:`, named sections with element counts, closing `Visual style:` paragraph as style guard. Used for dashboards and structured layouts.

### Structure D: Pseudo-Code DSL *(new Aug 2026)*
Treat the prompt as a program: variable assignments (`INPUT ::= keyword`, `W := derive_word(INPUT)`), a LAYOUT_SOLVER ASCII diagram of the canvas, SEMANTIC_ASSIGNMENT/FUSION rules mapping concepts to slots (`A.body_part -> glyph_stroke`, `energy_propagation -> concentric_marks`), BRUSH_PHYSICS proportionalities (`stroke_width(t) ∝ pressure(t)`), or `AI_INFER(...)` calls inside JSON values ("ai picks the rest"). Also seen as `THEME=/STYLE=/PALETTE=` headers + `DO:`/`RULES:` blocks. The model resolves the grammar into an image; best for generative-series systems and calligraphy/typographic fusion where literal description fails.

## Key Techniques

- **Exact Counting**: "exactly 4 cards", "exactly 8 rows" — prevents arbitrary additions
- **Spatial Anchoring**: "top-left header", "bottom-right product card" — positions by name
- **Visual Style Guard**: Closing paragraph summarizing full aesthetic — prevents drift
- **Face Lock**: "maintain exact facial structure from reference with 100% accuracy, preserve micro-details, no beautification"
- **Negative Prompts**: "negative prompt: distorted face, plastic skin, beauty filter effect"
- **Cross-Reference Mapping**: "REFERENCE_0 as identity, REFERENCE_1 as layout" — number references explicitly
- **Color Science**: "ultra-clean cinematic color grading with high color separation, natural saturation, deep contrast, HDR dynamic range"
- **Subsurface Scattering**: "soft natural skin with visible pores, smooth tonal transitions, subtle subsurface scattering"
- **Physics-Causality VFX** *(new Aug 2026)*: describe effects as physical actions with a source, weight, and landing point, plus selective environmental reaction — "airflow starting dense at the vent, widening diagonally downward, diffusing softly on the subject; only the blown area frosts blue while the environment stays hot". Makes VFX feel causal, not pasted-on.
- **Percentage-Grid Coordinates** *(new Aug 2026)*: place objects and text zones by frame-percentage boxes — "pot center at 62% horizontal / 64% vertical, occupying 38% of frame width; text zone from 7-42% horizontal, 9-47% vertical". Pairs with a **color budget** ("52% warm white, 18% syrup gold, 20% pear milk white, 5% glass gray, 5% dark brown text").
- **Adjacent-Genre Exclusion** *(new Aug 2026)*: end portraits with the genres it must NOT drift into — "not a bedroom scene, bridal portrait, flower field, or luxury campaign composite". Different from defect negative prompts; this pins the intended genre.
- **Selective Colorization** *(new Aug 2026)*: "mostly monochrome black-and-white with only the camisole softly colorized in muted rose" — one accent element in color against a B&W frame.
- **Degraded-Reference Identity Extraction** *(new Aug 2026)*: Face Lock for low-quality references — enumerate the identity features to extract and continue ("face shape ratio, eye shape and distance, eyebrow shape, nose structure, mouth shape, ear contours, hairline, facial fleshiness, expressions, temperament"), explicitly state that even childhood/low-res/blurry/old photos are acceptable inputs, and command "maintain the original identity so the result is clearly the same person as in the photo".
- **Anti-Shortcut / Output Exclusions** *(new Aug 2026)*: A third negative tier — block the model's *lazy default solution*, not defects or genres. As a JSON key: `"output_exclusions": ["Do NOT include a small inset photo of the reference in the corner — the output is the illustration ONLY, full-bleed"]`. As prose: "Do not simply place the logo on a generic can. Reimagine the identity into..." Forces full reinterpretation instead of paste-on shortcuts.
- **Split-Frame Analytical Deconstruction** *(new Aug 2026)*: Divide the canvas 50/50 — top half preserves the uploaded photo (identity, perspective, color atmosphere; only light editorial grading, no subject distortion), bottom half redraws the subject as an isometric/axonometric deconstruction study (watercolor, Da Vinci manuscript, etc.) with explicit anti-collage bans ("do not paste the photo directly, no before/after comparisons") and **subject-type-aware decomposition rules**: buildings/objects split into 2–5 layers along real axes; living subjects stay whole ("dismemberment, dissection, or mechanical partitioning is prohibited") expressed only through outline overlap and pose layers. One stable anchor layer lets the viewer mentally reassemble the subject.
- **Medium-Partition Hybrid** *(new Aug 2026)*: Assign a different medium per region and forbid bleed — "Only the character should be illustrated [2D black-ink line art, white interior, sticker-like outline]; everything else must remain photorealistic. Do not turn the background into anime." Pairs with physical integration cues (feet contact the ground, matched scale/perspective, natural shadows) so the illustrated element reads as physically *inside* the photo.
- **Chained Retrieval-Transform Steps** *(new Aug 2026)*: Two-step workflow where Step 1 delegates retrieval to the model itself — "Step 1: Search for the 10 most classic stills from [movie]. Use each as a reference image. Step 2: Replace the main characters with [targets], maintaining the characters' emotions, screen grain texture, and color texture. Output each image." Useful when you don't have references on hand; the texture-preservation clause keeps the swap diegetic.
- **Source-Look Preservation (Anti-Upgrade)** *(new Aug 2026)*: In edits that swap identity (or restyle) a base photo, enumerate the *flaws to keep* and ban polish — "Preserve the raw phone-photo look: slight motion blur, JPEG compression, sensor noise, imperfect crop, real shadows, uneven indoor light and natural skin texture. Do not make it look like a studio render." The model's edit default is to beautify; keeping the degradation is what makes the result read as the same authentic photo. Inverts negative-prompt logic: the "defects" are the spec.
- **Element-Scoped Negatives** *(new Aug 2026)*: Point negatives at specific elements of *your* composition, not generic artifacts. Two forms: **fragile-detail protection** ("Do not make the front leg small; Do not omit the sheer hem of the white lace" — defends details the model tends to shrink/drop) and **focus-stealing prevention** ("avoid the title engulfing the subject, and background props becoming the protagonist" — caps decorative/text elements from overwhelming the subject). Generic negatives are hygiene; element-scoped ones encode predicted failure modes for this specific layout.
- **Enumerated Prop-List Inventory** *(new Aug 2026)*: Exact Counting applied to a whole scene — list every visible object as a numbered inventory with count + position + micro-description ("Include exactly 14 visible prop groups: 1 beige blanket spread across the ground, 1 light pillow at far left, 1 open sketchbook near the woman's left hand…"). Doubles as spatial anchoring and a text-rendering manifest for labeled props. Use for flat-lays, table/desk/picnic scenes, and lifestyle photos the model would otherwise over- or under-populate.
- **Recontextualized Reference Transformation** *(new Aug 2026)*: Move a single reference object into a new genre as N physical instances — "transform it into a grounded photorealistic still-life scene instead of an action portrait. Remove the wearer and motion trails. Show the mask design as a collection of exactly 7 physical helmets stored in an old teal wooden cabinet… Preserve the red leather, metal studs, cracked seams from the reference, but make all helmets tangible objects with realistic scuffs." Strips source-genre clichés, slots each instance into the composition, and carries a material checklist over. The "instead of [default genre]" pivot blocks the model's character-render default.
- **Normalized 100×100 Grid Series Contract** *(new Aug 2026)*: Percentage-grid coordinates (see above) applied to a *series*: define every zone on a normalized 100×100 grid ("Frame: x=5–95, y=8–92. Landmark zone: y=18–58. Location-name zone: y=68–88"), add a landmark hierarchy by % height, then lock everything with an enumerated "SERIES CONSISTENCY: keep frame, grid, typography, palette, lighting, camera identical across every location. Change only [whitelist]" and a closing "FINAL QUALITY CHECK" restating acceptance criteria. Makes every image in a collectible set structurally interchangeable.
- **Anti-Cliché Cultural Adaptation** *(new Aug 2026)*: Adjacent-genre exclusion specialized for destination/place imagery — ban stock-poster failure modes ("no oversized landmarks, excessive cultural symbols, photorealistic collage, generic stock imagery") plus a positive authenticity mandate: "Prioritize the authentic visual character of the chosen city. Do not force elements that do not belong there. Adapt architecture, vegetation, atmosphere and color palette specifically to the city."
- **Fixed-Anchor Campaign Grid** *(new Aug 2026)*: For multi-panel poster series, declare one immutable object anchor ("the pho bowl must remain the absolute visual hero in every panel", same camera angle/scale/perspective in all panels, "acting as the fixed campaign anchor") then govern variation with named meta-directives: **Style lock:** pins the genre ("Cannes-level print campaign execution, not illustration, not 3D render"); **Transit logic:** subtraction mandate ("reduce small labels, shorten copy, preserve clean negative space, avoid flyer-like density"); **Orbit logic:** per-panel variation system (panel 1 descending diagonal text flow → panel 2 mirrored inward diagonal → panel 3 circular orbit around anchor → panel 4 tighter circular return that "visually resolves the campaign"). Separates what stays fixed (anchor, background alternation, structure) from how each panel moves.
- **Protected Wardrobe Contract** *(new Aug 2026)*: For complex/asymmetric outfits, open with an immutability rule: "PROTECTED WARDROBE RULE — HIGHEST PRIORITY: Treat each garment description as immutable source identity. Preserve construction, parts, hardware, material, pattern, and every registered graphic — its surface, side, orientation, scale, colors, content, spelling, and count — unless a later instruction explicitly changes it." Define scoped override semantics (a MATERIAL CHANGE substitutes only the named material phrase; a FINAL WORN STATE overrides only use/position/side/layering/drape for the items it explicitly names) and a **VIEW-CONDITIONAL BODY-SIDE MAP** ("front view — wearer-left is image-right; back view — wearer-left is image-left; apply the state only to the named anatomical side, never mirror or duplicate it"). Kills the two classic failures: garments redesigned mid-prompt and asymmetric details hallucinated onto both sides.
- **Agency Creative Brief** *(new Aug 2026)*: Structure the prompt as an all-caps advertising brief: CREATIVE DIRECTION (visual language + "Do not copy any specific reference composition. Extract the common principles and build an original execution" + "The visual must communicate the idea before the viewer reads the copy"), CAMPAIGN DNA (Brand / Hero product / Concept / Personality + color system with roles: "Dominant red (#E31837)… The red must own the frame immediately"), BACKGROUND with **Allowed/Forbidden lists** ("Forbidden: random restaurant interior as default, dirty kitchen, city street, collage clutter"), HERO PRODUCT with **frame-occupancy spec** ("Product occupies roughly 50–65% of the frame width unless the idea needs scale contrast"; "believable grease sheen, not plastic CGI"), TYPOGRAPHIC SYSTEM ("Typography is hierarchy, not decoration. Do not flood the frame with copy.").
- **Timed Storyboard Script** *(new Aug 2026)*: Encode motion inside a still: numbered timecoded scenes (`1 | 0:00–0:03 — STORM CLOUDS`) where each scene carries its own Visual / Action / Labels / VO / SFX / Camera / Transition lines, plus a bottom narrator spec. Timecodes force one beat per panel; VO lines become per-panel captions; Camera and Transition lines dictate per-panel composition and energy. Produces professional animatic-style educational storyboards from one prompt.
- **Named Effect Menu (one-of-N)** *(new Aug 2026)*: A customizable header block (Subject / Interference / Title / Palette / Mood) followed by a dictionary of precisely-defined named treatments — "Color Split: translucent bands selectively shift portions of the portrait; Narrow Light Beam: a single beam cuts across the face; Horizontal Cut: bold bands interrupt the portrait and interact with oversized typography; Motion Veil: sharp portrait with selective horizontal motion trails" — constrained by "Use only one primary interference method". Running the template N times with different menu choices yields a coherent series; the one-only rule prevents effect stacking. Typography treated as compositional actor ("letters crop beyond the frame, overlap the subject, disappear behind the body").
- **Pipeline Anchor Declaration** *(new Aug 2026)*: A Step-1 prompt that manufactures the reference for Steps 2+: explicitly declare the downstream role ("generate a new single anchor image… the sole design standard for character, costume, and sword for subsequent three-view sheets") and optimize for expandability, not standalone beauty ("clear shapes for bangs, sides, and back of the head… a silhouette easily recognizable in video"; costume "front, side, and back structures can be naturally developed"; fixed 1:1 head-to-toe fit "without strain"). Written in a markdown-header DSL dialect (`# CUSTOM_SWORD_ANCHOR`, `## [Purpose]`) — fifth dialect of the pseudo-code DSL family (Structure D).
- **Split-Screen Controlled-Variable A/B** *(new Aug 2026)*: Same subject rendered twice with exactly one named delta plus one label box per panel — "left panel slightly more textured, crisp… right panel slightly smoother and more airbrushed" + labels ("OpenAI 官方" / "Azure West US 3"), closed by "similar enough to clearly compare rendering differences, but not identical". The single-variable delta + similarity band keeps comparisons honest; use for model face-offs, before/after, and settings comparisons.
- **Rebus Visual-Word Substitution** *(new Sep 2026)*: Split-frame photo-transform where the lower half becomes a "visual sentence" — generate a short poetic sentence from the photo's mood, then replace selected nouns/action/emotion words *inline* with small redrawn image fragments on colored blocks: "text → image-word → text → image-word → text" reading logic. Hard rule: "Once a word is replaced by an image, the word must not be written in text again — the sentence must rely on 'text + images' to be fully understood." Image-words vary in size by semantic importance (some word-sized, some focal), blocks use varied crops/aspect ratios derived from the photo's own vivid colors, and generous white space makes the layout read as an art-magazine visual poem. Explicit bans: sticker-wall aesthetics, card grids, decorative-only illustrations, images without deleting the corresponding word.

## Featured Patterns (top community outputs)

1. **Exploded Product Diagram** — JSON with `centerpiece: vertically stacked exploded view` + `callout_labels` split left/right
2. **Broadcast UI Mockup** — Goal/Canvas/Sections: `top_header`, `mid_left`, `bottom_left_chat`, `bottom_right_product_card`, `bottom_bar`
3. **Illustrated Map** — JSON with `sections[]` array of landmarks/food spots + `legend` + `centerpiece` mascot
4. **Recipe Card** — Goal/Canvas with `Info badges`, `Ingredients section` (exact counts + icons), `Steps` (numbered badge grid)
5. **Before/After** — Cross-reference: "Using REFERENCE_1 as current, REFERENCE_0 as identity. Keep [elements] unchanged. Only correction is [fix]."
6. **Cinematic Action** — Labeled sections: Shot Type / Subject + Face Lock / Setting / Action / Attire / Lighting & Color / Technical / negative prompt
