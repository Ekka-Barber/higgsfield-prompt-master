# /hf-brand — logos, wordmarks & identity

Read `../_shared/arabic-rules.md` first — an Arabic wordmark is a letterform
problem, and this is where letter shaping matters most. Also read
`../_shared/typography.md`: font *names* are style hints, not specifications —
which is exactly why a rendered logo is a concept, never a deliverable.

## Set expectations honestly, up front

Image models produce **logo concepts and directions**, not production logos. A
real logo is vector, kerned, and reproducible at 12mm. What you get here is a
strong visual direction to redraw properly.

Say it once, plainly, then get on with making the concept excellent.

For an Arabic wordmark specifically: a rendered logo with one broken letter
connection is unusable, and this is the highest-risk text job in the whole
skill. Offer to generate **the mark/icon** clean and set the wordmark in type.

## Logo types — pick one

| Type | What it is | Arabic note |
|---|---|---|
| **Wordmark** | the name, styled | Kufi = modern; Diwani = luxury |
| **Lettermark** | initials / monogram | single Arabic letter can be stunning |
| **Icon + lockup** | symbol beside text | lockup order flips for RTL |
| **Emblem** | text inside a shape | strong for heritage/government |
| **Abstract mark** | non-literal symbol | no text = no text risk |

## Arabic wordmark craft

- **Geometric Kufi** is the workhorse of modern Arabic branding: angular,
  modular, grid-based, reads as contemporary and confident.
- **Diwani** signals luxury, hospitality, and heritage prestige.
- A **single-letter monogram** (ع، م، ن) in Kufi is a genuinely strong,
  low-risk direction — one glyph, minimal error surface.
- Ask for **"clean vector-style flat shapes, solid fills, no gradients, no
  bevels, no drop shadows, plain background"** — this is what makes a concept
  redrawable.
- **Negative space** and letter-counter play is where Arabic marks get elegant.

## Bilingual lockups

- Arabic **above** Latin, or Arabic **right** of it — Arabic leads.
- Arabic set **110–125%** of the Latin size for optical balance.
- Shared alignment axis; separate lines; never interleaved.
- The two scripts should feel like **one family** — matched weight, matched
  terminal style, matched contrast. Say "visually harmonised bilingual lockup".

## Identity systems

When asked for a full identity, generate **separate assets**, not one crowded
board:
1. Primary mark on plain background
2. Colour palette as swatches with hex values
3. Pattern / motif tile (arabesque, girih, Sadu, Najdi triangles)
4. Application mockup (signage, packaging, card)

Hex codes: state them explicitly (`#1B4332`). Both models honour named hex
better than "dark green".

## Grill

1. Brand name, verbatim, in Arabic (and Latin if bilingual)?
2. Sector and register — luxury, tech, hospitality, government, youth?
3. Wordmark, monogram, icon+lockup, or emblem?
4. Existing colours to lock to?

Follow-up: is this exploration (many directions) or refinement of one idea?
That changes whether you produce variants or one considered concept.

## Routing

Arabic lettering → **Nano Banana Pro** (`gemini-3-pro-image`). Abstract mark
with no text, or a precise geometric construction → **GPT Image 2** works well.
Square `1024x1024` on a plain background is the right canvas for a mark.
